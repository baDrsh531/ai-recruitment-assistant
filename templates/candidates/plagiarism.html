Des candidats differents dont le CV se ressemble : copie, modele partage dans une promotion, agence qui reformate le meme profil pour deux clients. A ne pas confondre avec Doublons, qui cherche une meme personne sous deux dossiers.

Le fichier strictement identique est deja traite ailleurs : l'empreinte du contenu est unique, et redeposer le meme octet ne cree rien. Reste le cas difficile — deux fichiers differents dont le texte se recouvre.

Comment la mesure evite le tout-venant

« Experience professionnelle », « Langues : francais, anglais », « Permis B » se retrouvent dans un CV sur deux. Une mesure naive rapprocherait tout le monde de tout le monde.
